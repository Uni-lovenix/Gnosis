## 依赖排序

1. Python 后端服务骨架（FastAPI + 进程管理） → 桌面端能拉起。
2. `DataSource` 接口与 ES 适配器 → 文件与 AI 可写入。
3. embedding 服务（BGE-M3） → 切片可向量化。
4. 文件解析器 → 接入切片与 embedding。
5. PostgreSQL / MySQL / 向量数据库适配器 → 多数据源承诺达成。
6. Electron 主进程 IPC 与状态机 → 桌面端可达。
7. React 渲染层 → 用户可操作。

## 已知缺口与未决项

- 模型权重来源未指定（BGE-M3 走 HuggingFace 还是 ModelScope）。
- 向量数据库选型未定（Milvus / Qdrant / pgvector / chromadb 等）。
- 部署方式未定（本地单用户 / 内网共享）。
- 这些将在细化阶段（elaboration）的架构基线中收敛。
