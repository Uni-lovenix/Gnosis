## 迭代协议

每个迭代开始前，规划者必须制定迭代协议，包含：

- 迭代目标
- 迭代范围
- 实施计划
- 交付物
- 退出标准

开发者按迭代协议开发；评估者按迭代协议和退出标准校验，发现问题反馈给对应开发者修改，通过后进入下一迭代或阶段验收。

## 通用退出检查

任何迭代的退出标准除了完成迭代协议中的交付物外，还必须通过以下通用检查。这些检查与 `evaluator-rubric.md` 的可观测性维度一一对应，缺一不可：

- **运行时可观测性**：系统层的信号（日志 / 追踪 / 进程事件 / 健康检查）覆盖关键路径并能留证，回答"系统做了什么"。
- **过程可观测性**：本轮迭代的计划、评分标准、验收条件齐备且彼此对齐，回答"为什么这个变更应该被接受"。

未通过上述任一检查的迭代，评估者不得放行；交由对应开发者补齐后再次校验。
